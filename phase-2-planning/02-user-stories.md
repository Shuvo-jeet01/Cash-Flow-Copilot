# User Stories

Priority: P0 is required for pilot; P1 is valuable after the core is dependable; P2 is postponed.

## Treasurer

- **US-01 (P0):** As a treasurer, I can configure fiscal dates, currency, categories, and a minimum reserve so calculations follow our policy.
- **US-02 (P0):** I can upload a bank CSV, map columns, preview totals, and correct errors before saving so bad data does not enter the ledger.
- **US-03 (P0):** I can see and resolve possible duplicates so a retry does not inflate cash or expenses.
- **US-04 (P0):** I can record future commitments with amount, date, category, status, and evidence so obligations appear before payment.
- **US-05 (P0):** I can classify expected income by confidence and due date so uncertain money is not mistaken for cash.
- **US-06 (P0):** I can see the safe-to-spend number, formula, contributing records, cutoff date, and freshness so I can verify it.
- **US-07 (P0):** I can see 30/60/90-day projections and reserve warnings so I know when cash may become tight.
- **US-08 (P0):** I can manage reimbursement status and mark payment reference details so requests are not lost or double-paid.
- **US-09 (P0):** I can export the records and audit log so the organization is not locked in.
- **US-10 (P1):** I can save import mappings so recurring uploads take less time.

## President and advisor

- **US-11 (P0):** As a president, I can view organization-wide cash, commitments, forecasts, and assumptions without editing transaction history.
- **US-12 (P0):** As a president, I can compare event scenarios and record a decision and rationale so the process is consistent.
- **US-13 (P0):** As an advisor, I can read the full financial picture and audit history but cannot change financial records.
- **US-14 (P1):** As a reviewer, I can acknowledge a warning so others know it was seen without deleting it.

## Committee chair

- **US-15 (P0):** As a chair, I can see only my assigned budget’s approved, committed, spent, and remaining amounts.
- **US-16 (P0):** I can draft an event scenario for my budget but cannot approve it or turn it into commitments.
- **US-17 (P1):** I can submit a purchase/commitment request for treasurer review.

## Member

- **US-18 (P0):** As a member, I can submit a reimbursement with a receipt and see only my own request status.
- **US-19 (P0):** I receive a clear request-for-information state when evidence is missing.
- **US-20 (P1):** I receive status notifications without seeing internal financial details.

## Administrator and safety

- **US-21 (P0):** As an organization admin, I can invite, change, and revoke roles with all changes audited.
- **US-22 (P0):** As any user, I cannot access another organization by changing a URL or identifier.
- **US-23 (P0):** As an authorized reviewer, I can distinguish imported facts, manually entered facts, and scenario assumptions.
- **US-24 (P0):** As a user, I see an explicit stale-data warning when inputs are older than policy allows.

## Postponed stories

- **US-25 (P2):** Automatic bank and dues-platform synchronization.
- **US-26 (P2):** Automatic reimbursement payment.
- **US-27 (P2):** Automated dues reminders or privilege restrictions.
- **US-28 (P2):** Sponsor-facing portal and benefit fulfillment CRM.
- **US-29 (P2):** AI-generated recommendations. Any future AI output must cite exact source records, disclose uncertainty, and remain advisory.
